## How to use these

- **Default to the breakdowns.** `../INDEX.md` is the deduped rulebook and the numbered breakdowns carry the worked examples. The transcripts are ~452 KB of speech — reading one end-to-end to answer a question the index already answers is waste.
- **Reach for a transcript when** a generated doc needs a verbatim line, an exact number, or the full context around a rule the breakdown compressed (e.g. the precise CTA-doctrine wording in 03, the ABO→CBO mechanics in 08, the clip-selection prompt engineering in 09).
- **Treat them as source, not output.** Nothing here is copied into a generated `marketing-plan/`; the plan cites lesson numbers, and the lesson docs point back here.
- These are unedited speech-to-text: expect disfluencies, mis-transcribed names, and speaker-attribution drift. Verify any number against a second mention before putting it in a client-facing brief.
